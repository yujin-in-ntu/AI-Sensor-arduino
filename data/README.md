# 공개 카메라 예제 데이터

카메라 데이터 수집이 어렵거나 포트·카메라 문제를 아직 해결하지 못한 학생도
학습 단계를 실행할 수 있도록 프로젝트에서 직접 촬영한 숫자 `0~3` 예제를
포함합니다.

```text
example_camera_full/<숫자>/
    OV7675에서 받은 160×120 회색조 원본 PGM, 숫자별 20장

example_camera_digits/<숫자>/
    현재 전처리 규칙으로 만든 28×28 학습용 PGM, 숫자별 20장
```

총 파일 수는 원본 80장과 전처리 이미지 80장입니다. 두 폴더의 파일 이름이
같으면 같은 촬영에서 나온 원본과 전처리 결과입니다.

개인이 새로 촬영한 데이터는 다음 폴더에 저장되며 Git에 올라가지 않습니다.

```text
camera_full/
camera_digits/
```

바로 학습하거나 원본부터 다시 전처리하는 명령은
[예제 데이터 실습 문서](../docs/EXAMPLE_DATA.md)를 확인하세요.
